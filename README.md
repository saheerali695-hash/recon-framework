# Automated Recon Framework (recon_tool.py)

Automated reconnaissance and vulnerability scanning workflow built in Python for authorized security testing and lab environments.

## Features
- Subdomain enumeration with Amass
- Top port and service detection with Nmap
- HTTP headers and robots.txt check
- Web crawling with Katana
- Directory and file discovery with Gobuster
- Parameter discovery with Arjun
- Vulnerability scanning with Nuclei
- JSON and HTML report generation

## Usage
python3 recon_tool.py <authorized-domain>

## Disclaimer
Use only on systems and targets you own or have explicit permission to test.
